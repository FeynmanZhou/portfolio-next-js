## What is ORAS  

[ORAS](https://oras.land/) is a **CNCF open-source project** that extends the OCI (Open Container Initiative) distribution spec beyond container images. It enables developers to **push, pull, and manage OCI artifacts** such as SBOMs, signatures, provenance, and AI/ML models across container registries.  

By integrating with Azure Container Registry and other registries, ORAS has become a **critical tool for secure software supply chain and multi-artifact management** in cloud-native ecosystems.
