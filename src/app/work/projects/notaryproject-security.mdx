## What is Notary Project  

[Notary Project](https://notaryproject.dev/) is a **CNCF open-source initiative** that standardizes signing and verification of software artifacts. It enables developers and enterprises to **secure the software supply chain** by providing cryptographic integrity and provenance for container images and OCI artifacts.
